# Diseño - Capturas y Referencias

Sube aquí tus capturas/PNGs que quieras replicar en la app.

Recomendaciones:

- Formato: PNG o JPG (preferible PNG).
- Densidad: usa resolución del emulador/teléfono (ej. 1080x2400) para precisión.
- Un archivo por pantalla/estado.

Convención de nombres sugerida:
<seccion>**<pantalla>**<estado>\_\_<breakpoint>.png
Ejemplos:

- home**jobs_list**default\_\_1080x2400.png
- home**filters**expanded\_\_1080x2400.png
- gigs**list**empty_state\_\_1080x2400.png
- streaks**dashboard**daily_checkin\_\_1080x2400.png
- job_detail**applied**1080x2400.png

Opcional: añade un TXT/MD con el mismo nombre para notas rápidas:

- colores: hex (#2F6FED, #10B981, ...)
- tipografía: familia/pesos si aplica
- espaciados: paddings/margins clave
- interacciones: qué pasa al pulsar X
