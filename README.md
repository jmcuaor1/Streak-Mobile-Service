## 📝 Descripción
**Streak: Mobile Service** es una aplicación que guía e incentiva a candidatos a seguir buscando empleo según su **perfil**, **vacantes disponibles**, **contactos y amigos**.  

Con **gamificación** y **notificaciones push** buscamos prolongar el **Life Time Value** de los candidatos mediante:  
- 🔔 Recordatorios y tips personalizados.  
- 🏆 Retos diarios/semanales.  
- 🤝 Conexiones con otros usuarios.
