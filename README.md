## 📝 Descripción
**Streak: Mobile Service** es una aplicación que guía e incentiva a candidatos a seguir buscando empleo según su **perfil**, **vacantes disponibles**, **contactos y amigos**.  

Mediante estrategias de **gamificación**, buscamos **prolongar el Life Time Value** de los usuarios, motivándolos con:
- 🔔 **Notificaciones push** con recordatorios y tips.  
- 🏆 **Retos personalizados** según avances.  
- 🤝 **Conexiones** con amigos y contactos para mantener el impulso.
